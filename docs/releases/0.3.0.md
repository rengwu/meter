Yacht is now **Meter**. Look for the yellow parking-meter icon in Applications. Download `Meter.dmg`, open it, and drag `Meter.app` into Applications. Meter supports macOS 13 and later on Apple Silicon and Intel.

### Upgrading from Yacht or Ration

1. If you use **Launch at login**, turn it off in the old app, then quit the app.
2. Open Meter. On first launch it copies your registered accounts, settings, and cached readings. If both Ration and Yacht have saved settings, Meter uses Ration’s. Existing Claude usage taps keep working.
3. To start Meter automatically, enable **Launch at login** in Meter Settings.
